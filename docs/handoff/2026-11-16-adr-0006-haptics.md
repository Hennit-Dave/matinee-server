# Handoff: ADR 0006 addendum for `expo-haptics` (branch `docs/adr-0006-haptics-installed`)

Docs only, no code. ADR 0006 (mobile native module list) still said `expo-haptics` was "recorded but not installed until the slice that first uses them". It is now installed and in use (matinee-mobile #26, merged), so the ADR got a dated addendum.

## What changed
- **`docs/decisions/0006-mobile-native-module-list.md`:** one appended section, `## Addendum — 2026-11-16`, in the same style as the existing 2026-11-13 addendum. It says `expo-haptics` is installed in `matinee-mobile` at Expo SDK 58's pinned `~58.0.8` (via `expo install`), is used on the seat-selection screen (a tick on every pick and drop, a warning at the 8-seat cap) through a shared helper at `src/lib/haptics.ts`, and ships in Expo Go, so it needs no EAS or custom build. It states that it supersedes only the "not installed until the slice that first uses them" remark, for `expo-haptics` alone.
- The original Decision section, the table and the 2026-11-13 addendum are untouched: the diff is 22 lines added and 0 removed.
- One line goes slightly beyond the three facts asked for, and is easy to delete: the table's "Needed for" cell for this module reads "seat-select **and** payment-confirm haptics (D2.6)", so the addendum notes that only the seat-select half is built and the payment-confirm haptic comes with the payments slice. Without it a reader could think the row was fully done.

## How the claims were checked
Against `matinee-mobile` `main` at `b5a6153` (the #26 squash), through the GitHub API, not from memory:
- `package.json` has `"expo-haptics": "~58.0.8"` (and `"react-native-worklets": "0.13.0"`).
- `src/lib/` holds `haptics.ts`, `hapticsCore.ts` and `hapticsCore.test.ts`.
- The only caller is the seat screen, which calls `haptics.selection()` and `haptics.warning()`.
- Expo Go ships it: `~58.0.8` is in Expo SDK 58's `bundledNativeModules.json`, and Expo Go 58.0.5's native code contains `expo/modules/haptics/HapticsModule` (read from the APK during the mobile work, evidence in `matinee-mobile/docs/evidence/seatmap/haptics.txt`).
